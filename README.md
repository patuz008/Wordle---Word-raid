
## 🎯 Wordle --> Word Raider
Inspired by wordle

A terminal-based word guessing game inspired by Wordle. Test your vocabulary and deduction skills to guess the hidden word within 6 turns!


# 🎮 How to Play
1. The game selects a random word from words.txt
2. Enter a guess matching the word's length (e.g., 5 letters)
3. Interpret feedback:
   + `s` → Correct letter in correct position
   + `[a]` → Letter exists but in wrong position
   + `_` → Letter not in word
4. Use the tracked lists:
   + Misplaced letters: Known letters needing repositioning
   + Incorrect letters: Letters eliminated from future guesses
5. Win by guessing correctly within 6 turns! Type stop anytime to quit.
